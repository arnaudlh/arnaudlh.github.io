Durant cette semaine à Houston, se déroule le TechED, suivons ensemble quelques unes des annonces partagées dans le keynote du jour 1 concernant Azure, la productivité des utilisateurs et la gestion des périphériques mobiles :

<!-- truncate -->

-   Azure RemoteApp

-   Il s’agit ici d’exécuter des applications directement depuis Azure, comme on le fait depuis quelques temps déjà avec Windows Server avec les Remote Desktop Services – RemoteApp.
-   Le client Remote Desktop permet d’accéder aux applications depuis n’importe quelle machine !
-   Le service est disponible en preview et inclus sans cout supplémentaire.
-   Plus d’infos : [http://azure.microsoft.com/en-us/services/RemoteApp/](http://azure.microsoft.com/en-us/services/RemoteApp/ "http://azure.microsoft.com/en-us/services/RemoteApp/") 

-   Azure Active Directory Premium

-   Azure AD, c’est 2 Milliards d’authentifications par jour ces derniers mois!
-   Nouvelle version de DirSync
-   Nouveau moteur de synchronisation Azure AD Sync
-   Azure Multifactor Authentication s’enrichit du contexte de l’adresse IP, pour définir des adresses depuis lesquelles on ne demandera pas de multifacteur.
-   Cloud App Discovery pour donner une vision globale des applications de l’organisation qui intègrent Azure: [essayer ici](http://appdiscovery.azure.com/)

-   Annonce de la feuille de route pour Windows Intune

-   Gestion de Office pour iOS et Android
-   Outil de déploiement générique d’application avec ses paramètres (app wrapping tool)
-   Navigation protégée par site Web pour iOS et Android.
-   Stratégies d’accès conditionnelles pour applications, paramètres (certificats, profiles VPN etc.) et information (accès à l’information uniquement si le périphérique est géré)

Vous pouvez trouver un certain nombre de sessions live depuis [https://channel9.msdn.com](https://channel9.msdn.com)

Les annonces concernant le Datacenter sont chez [Stanislas](https://aka.ms/stanislas)
