IPAM (IP Address Management) est une nouvelle fonctionnalité de Windows Server 2012 qui vous donne la possibilité de découvrir, surveiller, auditer et gérer l’espace d’adressage IP utilisé sur un réseau d’entreprise. IPAM permet d’administrer et de surveiller les serveurs exécutant le service DHCP ou DNS et récolte les informations provenant des contrôleurs de domaine et des serveurs NPS.
