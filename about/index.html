About

Hi, I'm Arnaud. I build a thing or two @ Microsoft — Azure, infrastructure as code and AI-assisted developer tooling. I'm based in Singapore.

This blog has been running since 2012, first in French while I was an infrastructure architect at Microsoft France, then in English covering Azure networking, security, governance and Cloud Adoption Framework landing zones with Terraform.

What I work on

  • Azure landing zones — Cloud Adoption Framework (CAF) landing zones with Terraform: templates, modules and the rover toolchain to scaffold enterprise-scale Azure environments.
  • Secure my code — Security guidance, guardrails and agents for GitHub Copilot to help developers ship secure code by default.
  • Git-Ape — Agent-driven Azure deployments from GitHub: requirements, ARM templates, policy checks and deployment in one guided flow.
